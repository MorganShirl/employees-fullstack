## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please do **not** open a public GitHub issue.

Instead, please report it privately:
1. Navigate to the **Security** tab of the repository.
2. Click **Report a vulnerability** to open a private advisory.
3. Provide a descriptive summary of the issue, the affected component, and steps to reproduce it.

**What to expect:**
* **Acknowledgement:** You will receive an initial response to your report within 48 hours.
* **Updates:** If the vulnerability is accepted, you will be kept in the loop regarding the patch timeline and the disclosure plan.
* **Resolution:** Once the patch is merged, a public security advisory will be published.
